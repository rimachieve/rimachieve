## How I got here

1. **만드는 사람** — 방송과 SNS 현장에서 콘텐츠가 기획되고 만들어지는 과정을 배웠어요
2. **읽는 사람** — 댓글과 반응에서 고객의 진짜 불편을 찾고, 콘텐츠로 가설을 세워 실험하고, 숫자로 다음 결정을 내리는 법을 익혔어요
3. **지금** — 그 흐름에 필요한 도구까지 직접 만듭니다. 고객 분석 → 가설 → 실행 → 성과 분석 → 개선, 이 과정을 AI로 더 빠르게 돌리는 마케터가 되는 중이에요
